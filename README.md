# 📝 Wordマクロ ＆ 業務効率化ツール一式

## 🎯 本リポジトリの概要（就職活動向けポートフォリオ）
本リポジトリは、大学でのAI（VAEを用いた画像異常検知）研究における論文執筆、実験レポート作成、および大量のデータ管理の効率を極限まで高めるために自作し、現在も実務運用している環境一式です。

単なるプログラムの学習にとどまらず、**「実務における明確な課題（ボトルネック）を発見し、テクノロジーを用いて自己解決する」** というプロセスを意識して開発・運用しています。

### 🛠️ 技術的なこだわり・工夫した点
1. **DRY原則（二重コードの禁止）に基づく共通化**
   背景色の塗りつぶし処理等において、同一コードの量産を避け、引数を用いた共通関数（`Apply ShadingRGB`）へ集約・構造化しています。
2. **UI/UXと堅牢性の両立（エラーハンドリング）**
   画像や表が選択されていない状態でマクロが実行された場合のエラー落ちを防ぐため、`On Error` 構文とユーザーへの適切な通知（`MsgBox`）を実装し、実用的な堅牢性を担保しています。
3. **人間工学に基づくパステルカラー選定**
   Word標準機能にある原色マーカーの視覚的疲労を軽減するため、目がチカチカしない上品なパステルカラーのRGB値をシミュレートして実装しました。

## 🚀 1. 収録マクロ・スクリプト概要

### 📄 文字・レイアウト整形
* `選択範囲の改行削除`: PDF等からのコピペ時に発生する邪魔な改行を自動消去
* `InsertSectionBreakNextPage`: 次のページから開始するセクション区切りを一発挿入

### 📊 表（テーブル）編集
* `AddBorders_OuterBold_InnerThin_Word`: 外枠を太線(1.5pt)、内側を細線(0.5pt)にして学会発表レベルの表にする
* `FillGray_And_BottomDoubleLine_Word`: セルを薄いグレーで塗りつぶし、下部に二重線を引く（見出し用）
* `FitTableToWindowWidth`: 表の横幅をページの印刷余白（左右幅）いっぱいに広げる

### 🖼️ 画像サイズ最適化
* `MaximizeImageSizeWithinPage`: 縦横比を保持したまま、文章下の残りスペースに100%ぴったり収まる限界最大サイズに自動調整

### 🔤 数式入力 ＆ パステルカラー装飾
* `InsertEmptyEquation`: 空の数式ブロックを挿入
* `FillYellow` / `FillGray` / `FillLightGreen` ... : 目がチカチカしない上品なパステルカラーでの塗りつぶし
