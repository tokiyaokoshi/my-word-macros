# 📝 Wordマクロ ＆ 業務効率化ツール一式

## 🎯 はじめに（マクロとは？）
**「マクロ（Macro）」** とは、WordやExcelでの「複数の面倒な手作業」を1つのボタンやショートカットキーで一瞬にして実行できるようにする**自動化プログラム**のことです。

本リポジトリは、大学での研究論文執筆に加え、建設コンサルタント企業での長期インターンシップにおける実務（現地調査計画書や業務報告書などのドキュメント作成）において発生する「画像のサイズ調整」「表の綺麗なデザイン化」「パステルカラーでのハイライト」といった繰り返しの作業を極限まで自動化し、数時間単位の業務効率化を実現するために開発したWord専用の自作マクロ（VBAコード）一式です。

学生としての研究活動にとどまらず、実際のビジネスの現場における「作業のボトルネック」を自ら発見し、テクノロジーの力で解決へと導くために構築・運用しています。どなたでも、以下の手順を踏むだけで、自分のWordを「実務特化型の超高速エディタ」に進化させることができます。

---

## 🚀 マクロの導入手順（初めての方向け）

このリポジトリのコードをあなたのWordに組み込み、使えるようにするための3ステップです。

### ステップ1：Wordの開発モードをオンにする
1. Wordを起動し、白紙の文書を開きます。
2. 画面上部のリボン（メニュー）の何もないところを右クリックし、**「リボンのユーザー設定」** を選びます。
3. 右側のリストの中にある **「開発」** のチェックボックスにチェックを入れて「OK」を押します。（これで上部に「開発」タブが出現します）

### ステップ2：コードを貼り付ける
1. 「開発」タブを開き、一番左にある **「Visual Basic」**（または `Alt + F11`）をクリックします。
2. 左側のツリーから `Normal` ＞ `標準モジュール` を探し、その中にある `NewMacros`（または任意のモジュール）をダブルクリックします。
   *(※「標準モジュール」が無い場合は、上部メニューの「挿入」＞「標準モジュール」をクリックして作成してください)*
3. 開いた白いキャンバスに、本リポジトリの `src/WordMacros.vba` の中身を**すべてコピーして貼り付け**、保存ボタン（フロッピーのアイコン）を押して閉じます。

### ステップ3：ショートカットキーを「一括設定」する
このマクロの真骨頂は「キーボードだけで全て操作できること」です。コード内にある自動セットアップ機能を使って、キーボードに機能を割り当てます。

1. Wordの「開発」タブ ＞ **「マクロ」**（または `Alt + F8`）をクリックします。
2. リストの中から **`SetupWordShortcuts`** という名前を選択し、**「実行」** をクリックします。
3. 「Wordのショートカットキー一括設定が完了しました！」というメッセージが出たら準備完了です！

---

## 📖 ショートカット操作一覧表の出し方

「どのキーを押したら何が起きるか忘れてしまった…」という時のために、現在割り当てられているすべてのマクロとショートカットキーのリストを、**Wordが自動的に表にして出力してくれるマクロ**も実装しています。

1. Wordの「開発」タブ ＞ **「マクロ」**（または `Alt + F8`）をクリックします。
2. リストの中から **`ExportCustomShortcutsCatalog`** を選択して「実行」します。
3. 数秒待つと、新しい白紙の文書が立ち上がり、**「ショートカットキー」「機能名」「詳しい説明」が綺麗にまとまった操作マニュアル表** が自動生成されます！これを印刷したり、PDFにして手元に置いておくと便利です。

## 📦 収録されている主な自動化機能の紹介

このマクロを導入することで、以下のような機能がキーボード操作だけで一瞬で実行できるようになります。

### 📄 文字・レイアウト整形
* **選択範囲の改行削除:** PDFからのコピペ時に混ざる邪魔な改行を自動一括消去。
* **セクション区切りの挿入 (`Alt + Return`):** 次のページから開始する区切りをパッと挿入。

### 📊 表（テーブル）の爆速編集
* **美しい論文用テーブル (`Ctrl + Shift + I` など):** 外枠を太線(1.5pt)、内側を細線(0.5pt)にするなど、学会発表レベルの表デザインを一瞬で適用。
* **表幅の自動調整:** 表の横幅をページの余白いっぱいに広げたり、文字の長さに合わせて最小化したりする処理をワンボタン化。

### 🖼️ 画像サイズの限界最適化 (`Alt + Shift + Down`)
* 画像の縦横比を保ったまま、「現在のページの下端（余白ギリギリ）」に100%ぴったり収まる限界の最大サイズを裏側で自動計算してリサイズします。次ページへの無駄な押し出しを防ぎます。

### 🔤 色彩工学に基づくパステルカラー装飾 (`Ctrl + Shift + W` など)
* Word標準の蛍光色マーカーによる視覚的疲労を防ぐため、RGB値を調整した「目がチカチカしない上品なパステルカラー（黄色、薄緑、グレーなど）」での塗りつぶしを実装しています。

---

## 🛠️ 開発における技術的な工夫（ポートフォリオアピール）
* **DRY原則（二重コードの禁止）:** 背景色の変更など、同じ構造のコード量産を避け、引数を用いた共通関数（`ApplyShadingRGB`）へ集約して美しい構造化を実現しています。
* **堅牢なエラーハンドリング:** 画像や表を選択せずにマクロを実行した場合のプログラムクラッシュ（エラー落ち）を防ぐため、適切な条件分岐とユーザーへの通知（MsgBox）を組み込んでいます。
